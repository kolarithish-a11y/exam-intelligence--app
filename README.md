# Exam Intelligence — Functional Mobile App

This package contains a working mobile-first PWA experience.

## Direct phone use
Open `index.html` in Chrome. The app works without a server for the included starter dataset and stores practice/progress in localStorage.

## Important data boundary
Starter content is explicitly sample/offline content. It is NOT presented as live current affairs.

## Production path
The existing Exam Intelligence backend/Next.js project contains the source ingestion, verification, archive, search, practice and learning infrastructure. A hosted deployment requires a cloud/GitHub/Vercel/Render account authorization and environment secrets. This package does not claim a live public deployment.

## Features in this functional build
- Daily command center
- Current-affairs categories
- Article viewer with static-GK and exam sections
- Search
- Historical archive UI
- Prelims practice with scoring
- Local mastery/progress
- Tutor interaction
- Dark mode
- Mobile bottom navigation
- Offline service worker shell
